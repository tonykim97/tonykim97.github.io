  1. KAIS
    A Deep Learning-Based Vision Approach for Railway Track Curve Radius Classification (Accept)
    Jeongwon Kim, Beomseong Kim, and Heesung Lee*
    Journal of the Korea Academia-Industrial Cooperation Society, 2026
    Abs DOI HTML

    With the advances in high-speed railway systems and autonomous train operation technologies, accurate recognition of track geometry and estimation of curve radius have become increasingly important. This paper proposes a deep learning-based algorithm for curve radius classification using railway images. Accordingly, a dataset containing various track directions and curve radii was constructed, and a Convolutional Neural Network (CNN)-based classifier using semantic segmentation results was combined with a vanishing point-based geometric curve radius estimation method. The confidence scores obtained from the two methods were fused using a weighted scheme to determine the final curve radius. The experimental results showed that the proposed algorithm achieved improved curve radius classification performance compared to the conventional method and successfully corrected several misclassified samples. These results show that geometric information obtained from vanishing points can complement the predictions of the CNN-based classifier. The proposed method uses both visual features and geometric information for curve radius classification and highlights the feasibility of railway image-based curve radius classification.

  2. KAIS
    Multimodal Image Fusion‑Based Glass Detection Algorithm
    Jeongwon Kim, Seungmin Lee, and Heesung Lee*
    In KAIS Spring Conference, Jun 2026
    Abs HTML

    본 연구는 투명 및 반사 특성을 갖는 유리 객체의 검출 성능 저하 문제를 해결하기 위해 RGB 영상과 열화상 영상을 결합한 멀티모달 영상 융합 기반 객체 검출 및 분리 기법을 제안한다. 일반적인 RGB 기반 객체 검출 모델은 유리와 같이 경계가 불명확한 객체에 대해 다수 객체를 하나로 인식하거나 일부 객체를 검출하지 못하는 한계를 가진다. 이를 해결하기 위해 본 연구에서는 YOLO 기반 객체 검출을 통해 유리 객체를 1차적으로 검출한 후, 열화상 영상으로부터 추출한 온도 분포 기반 경계 정보를 활용하여 객체 간 분리를 수행한다. 또한 RGB와 열화상 영상 간 정합을 기반으로 decision-level 융합을 적용하여 기존 검출 결과를 보정함으로써 검출 정확도를 향상시키고자 한다. 제안 기법은 별도의 모델 구조 변경 없이 후처리 단계에서 적용 가능하여 계산 효율성이 높으며, 산업 현장에서 실시간 적용이 가능한 유리 객체 검출 기술로 활용될 수 있다.

  3. IPIU
    Tempered Glass Detection and Tracking Algorithm Using Image Data
    Seungmin Lee, Jeongwon Kim, and Heesung Lee*
    In 38th Workshop on Image Processing and Image Understanding, Feb 2026
    Abs HTML

    본 연구는 영상 데이터를 이용한 강화유리의 검출 및 추적 알고리즘을 제시한다. 강화유리 생산 공정에서 촬영된 유리 영상은 투명성과 반사 특성으로 인해 기존 Semantic Segmentation 기반 유리 검출 기법의 적용에 제약이 있다. 이를 고려하여 다양한 영상 전처리를 수행하고, YOLO 기반 Object Detection 모델을 적용하였다. 강화유리의 이동은 컨베이어 벨트의 등속 운동을 가정하여 Kalman Filter를 이용해 추적하였다. 제안한 알고리즘은 실제 강화유리 생산 라인에서 취득한 영상 데이터를 대상으로 적용하였다.

  4. KSR
    Deep Learning‑based Railroad Track Detection Image Segmentation Algorithm
    Jeongwon Kim, Seungmin Lee, and Heesung Lee*
    In Proceedings of the KSR Conference, Oct 2025
    Abs HTML

    사전 학습된 모델을 새로운 데이터셋에서 활용하는 기존의 방법은 모델 가중치들을 미세조정하여 학습하는 방법이다. 하지만 특수한 도메인의 데이터 셋 학습이나 대규모 모델의 하위 계층의 수정이 필요한 작업에서 미세조정 방법은 효율적이지 않으며, 이를 극복하기 위한 새로운 접근 방식은 가중치를 동결시킨 모델을 활용하는 것이다. 본 연구에서는 대규모 데이터 셋으로 사전 학습된 영상 분할 모델들을 이용하여 선로를 분할하는 연구를 진행한다. 이를 통해 사전 학습된 모델들의 유용성과 철도 시스템에서의 활용 가능성에 대해 연구하고 이러한 모델들의 실제 적용 가능성에 대해서도 탐구하였다.
